# prompts/

Библиотеки промптов и хендоффы по ним. Каждая папка = один проект: файл-результат на языке целевой аудитории, `HANDOFF.ru.md` с контекстом, решениями, выводами и журналом запусков, `outputs/` с готовыми результатами прогонов промптов.

| Папка | Что внутри | Для кого |
|---|---|---|
| `nigerian-creator/` | `PROMPT_LIBRARY.md` — 42 промпта: TikTok, Reels, WhatsApp, Telegram; `HANDOFF.ru.md` — контекст, выводы и журнал запусков; `outputs/` — результаты прогонов, например 30 хуков из промпта 1.1 | Нигерийский Gen Z креатор-предприниматель (ивенты, еда, скинкер, цифровые хастлы) |
